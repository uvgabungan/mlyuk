Deploy Otomatis ke Vercel (1-Klik)

Kirim sinyal update/build ke Vercel langsung dari halaman ini tanpa perlu membuka terminal CMD.

Cara Buat Hook di Vercel:
  1. Buka vercel.com > pilih project streaming-web.
  2. Klik menu Settings > pilih Git.
  3. Scroll ke Deploy Hooks > buat nama hook > Create Hook.
  4. Salin URL hook dan tempel di kotak input sebelah kiri.
